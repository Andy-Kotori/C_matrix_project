# 矩阵计算库 (Matrix Computation Library)

这是一个高性能的C语言矩阵计算库，实现了矩阵的基本运算和高级功能，并提供了完整的性能测试框架。

## 项目简介

本项目实现了以下核心功能：
- **基本矩阵运算**：加法、减法、标量乘法、矩阵乘法、转置
- **高级矩阵功能**：多种行列式计算方法、多种逆矩阵计算算法
- **性能测试**：支持不同规模矩阵的性能测试和结果分析
- **内存管理**：使用内存栈机制统一管理动态内存分配
- **多格式输出**：支持文本和JSON格式的测试结果输出

## 编译说明

### 环境要求

- C编译器（GCC或兼容编译器）
- 支持C11标准
- Linux/Unix环境（或Windows下的MinGW）

### 编译步骤

1. **清理旧文件**（可选）：
   ```bash
   make clean
   ```

2. **编译项目**：
   ```bash
   make
   ```

3. **编译完成后**，会生成可执行文件 `matdemo`

### 编译选项说明

Makefile中使用的编译优化选项：
- `-std=c11`：使用C11标准
- `-O3`：最高级别优化
- `-march=native`：针对本地CPU架构优化
- `-ffast-math`：数学运算优化
- `-funroll-loops`：循环展开优化
- `-Wall -Wextra`：显示所有警告信息

## 运行说明

### 基本运行

编译完成后，直接运行可执行文件：

```bash
./matdemo
```

### 运行流程

程序执行分为两个主要部分：

1. **基础功能测试**：
   - 创建3×3测试矩阵
   - 演示加法、标量乘法、转置、乘法运算
   - 显示运算结果

2. **性能测试**：
   - 测试矩阵规模：1100×1100 到 2000×2000（步长100）（可自行更改）
   - 测试运算：加法、标量乘法、转置、乘法、行列式计算、逆矩阵计算
   - 测试次数：所有运算均测试20次
   - 计算并显示平均执行时间
   - 自动保存结果到 `results.txt` 和 `results.json`

### 测试结果

性能测试结果会自动保存到两个文件中：

1. **results.txt**：人类可读的文本格式，包含：
   - 测试环境说明
   - 各矩阵规模的平均执行时间
   - 详细的每次测试时间数组
   - 测试次数统计

2. **results.json**：机器可读的JSON格式，便于数据分析

## 核心功能说明

### 矩阵运算函数

| 函数 | 功能 | 时间复杂度 | 优化特性 |
|------|------|-----------|----------|
| `matrix_add()` | 矩阵加法 | O(n²) | 4路循环展开 |
| `matrix_sub()` | 矩阵减法 | O(n²) | 4路循环展开 |
| `matrix_scalar_mul()` | 标量乘法 | O(n²) | 4路循环展开 |
| `matrix_transpose()` | 矩阵转置 | O(n²) | 分块算法优化 |
| `matrix_multiply()` | 矩阵乘法 | O(n³) | 分块算法优化 |

### 行列式计算函数

| 函数 | 方法 | 适用场景 | 时间复杂度 |
|------|------|----------|-----------|
| `matrix_determinant_recursive()` | 递归Laplace展开 | 教学演示，小矩阵（≤10×10） | O(n!) |
| `matrix_determinant_gaussian()` | 高斯消元法 | 中等规模矩阵 | O(n³) |
| `matrix_determinant_lu()` | LU分解法 | 大规模矩阵 | O(n³) |

### 逆矩阵计算函数

| 函数 | 方法 | 适用场景 | 时间复杂度 |
|------|------|----------|-----------|
| `matrix_inverse_adjugate()` | 伴随矩阵法 | 教学演示，小矩阵（≤10×10） | O(n!) |
| `matrix_inverse_gauss_jordan()` | Gauss-Jordan消元法 | 中等规模矩阵 | O(n³) |
| `matrix_inverse_lu()` | LU分解法 | 大规模矩阵 | O(n³) |

### 优化特性

- **循环展开**：加法和标量乘法使用4路循环展开
- **分块算法**：转置和乘法使用分块算法提高缓存命中率
- **内存管理**：使用内存栈统一管理内存，避免内存泄漏
- **多算法支持**：为不同规模矩阵提供最适合的算法

## 注意事项

1. **矩阵规模限制**：递归算法（行列式和逆矩阵）仅测试10×10及以下矩阵
2. **内存需求**：大矩阵测试需要足够的系统内存
3. **随机数**：使用当前时间作为随机数种子，确保每次运行结果不同
4. **错误处理**：所有矩阵运算都有完整的错误处理机制
5. **结果异常**：某些运算可能显示为0.0000秒，可能是由于实现问题或数值精度问题

## 故障排除

### 编译错误

- **错误**：`gcc: command not found`
  - **解决**：安装GCC编译器：`sudo apt-get install gcc` (Ubuntu/Debian)

- **错误**：`undefined reference to 'sqrt'` 等数学函数错误
  - **解决**：确保链接数学库，Makefile中已包含 `-lm` 选项

### 运行时错误

- **错误**：`Segmentation fault` (段错误)
  - **可能原因**：内存不足，特别是对于大矩阵测试
  - **解决**：减少测试矩阵大小或增加系统内存

- **错误**：`Matrix creation failed` (矩阵创建失败)
  - **可能原因**：内存分配失败
  - **解决**：检查系统可用内存，或减小测试矩阵规模
