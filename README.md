# 矩阵计算库 (Matrix Computation Library)

这是一个高性能的C语言矩阵计算库，实现了矩阵的基本运算和高级功能，并提供了完整的性能测试框架。

## 项目简介

本项目实现了以下核心功能：
- **基本矩阵运算**：加法、减法、标量乘法、矩阵乘法、转置
- **高级矩阵功能**：行列式计算、伴随矩阵、逆矩阵
- **性能测试**：支持不同规模矩阵的性能测试和结果分析
- **内存管理**：使用内存栈机制统一管理动态内存分配

## 项目结构

```
matrix_project/
├── main.c              # 主程序，包含功能测试和性能测试
├── matrix.c            # 矩阵运算核心实现
├── matrix.h            # 矩阵库头文件
├── memstack.c          # 内存栈管理实现

```

## 编译说明

### 环境要求

- C编译器（GCC或兼容编译器）
- 支持C11标准
- Linux/Unix环境（或Windows下的MinGW）

### 编译步骤

1. **清理旧文件**（可选）：
   ```bash
   make clean
   ```

2. **编译项目**：
   ```bash
   make
   ```

3. **编译完成后**，会生成可执行文件 `matdemo`

### 编译选项说明

Makefile中使用的编译优化选项：
- `-std=c11`：使用C11标准
- `-O3`：最高级别优化
- `-march=native`：针对本地CPU架构优化
- `-ffast-math`：数学运算优化
- `-funroll-loops`：循环展开优化
- `-Wall -Wextra`：显示所有警告信息

## 运行说明

### 基本运行

编译完成后，直接运行可执行文件：

```bash
./matdemo
```

### 运行流程

程序执行分为两个主要部分：

1. **基础功能测试**：
   - 创建3×3测试矩阵
   - 演示加法、标量乘法、转置、乘法运算
   - 显示运算结果

2. **性能测试**：
   - 测试矩阵规模：100×100、500×500、1000×1000、10000×10000
   - 测试运算：加法、标量乘法、转置、乘法
   - 测试次数：
     - 100×100、500×500、1000×1000：各运算测试20次
     - 10000×10000：各运算测试5次（避免过长的测试时间）
   - 计算并显示平均执行时间
   - 自动保存结果到 `results.txt`

### 测试结果

性能测试结果会自动保存到 `results.txt` 文件中，包含：
- 测试环境说明
- 各矩阵规模的平均执行时间
- 测试次数统计
- 清晰的格式化输出

## 核心功能说明

### 矩阵运算函数

| 函数 | 功能 | 时间复杂度 |
|------|------|-----------|
| `matrix_add()` | 矩阵加法 | O(n²) |
| `matrix_sub()` | 矩阵减法 | O(n²) |
| `matrix_scalar_mul()` | 标量乘法 | O(n²) |
| `matrix_transpose()` | 矩阵转置 | O(n²) |
| `matrix_multiply()` | 矩阵乘法 | O(n³) |
| `matrix_determinant()` | 行列式计算 | O(n!) |
| `matrix_adjugate()` | 伴随矩阵 | O(n!) |
| `matrix_inverse()` | 逆矩阵 | O(n!) |

### 优化特性

- **循环展开**：加法和标量乘法使用4路循环展开
- **分块算法**：转置和乘法使用分块算法提高缓存命中率
- **内存管理**：使用内存栈统一管理内存，避免内存泄漏

## 注意事项

1. **大矩阵测试**：10000×10000矩阵乘法测试可能需要较长时间（约6分钟）
2. **内存需求**：大矩阵测试需要足够的系统内存
3. **随机数**：使用当前时间作为随机数种子，确保每次运行结果不同
4. **错误处理**：所有矩阵运算都有完整的错误处理机制

## 故障排除

### 编译错误

- **错误**：`gcc: command not found`
  - **解决**：安装GCC编译器：`sudo apt-get install gcc` (Ubuntu/Debian)

- **错误**：`undefined reference to 'sqrt'` 等数学函数错误
  - **解决**：确保链接数学库，Makefile中已包含 `-lm` 选项

### 运行时错误

- **错误**：`Segmentation fault` (段错误)
  - **可能原因**：内存不足，特别是对于大矩阵测试
  - **解决**：减少测试矩阵大小或增加系统内存

- **错误**：`Matrix creation failed` (矩阵创建失败)
  - **可能原因**：内存分配失败
  - **解决**：检查系统可用内存，或减小测试矩阵规模
